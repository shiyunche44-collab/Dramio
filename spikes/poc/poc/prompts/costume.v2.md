# costume.v2：角色定妆提示词（P0-06，Seedream 5.0）

相对 v1 只改两个设定板节（view_sheet、expression_sheet）：去掉剧集视觉风格 $style。
原因：v1 设定板把“冷蓝色雨夜”画成了背景（flash 苏晚三视图板、陆沉表情板），定妆资产应是中性棚拍。其它节与 v1 逐字相同。

每节是一个模板，`$变量` 在运行时从 DramaIR 的 `series` 与 `characters[]` 渲染（不另建角色结构，INV-02）。
公共变量：$style（series.visual_style）、$name、$gender（女性 / 男性）、$age、$appearance、$costume。
各节追加变量：view 节为 $view（正面 / 左侧面 / 背面），expression 节为 $expression（表情描述），
expression_sheet 节为 $expressions（顿号分隔的表情列表）、$count（表情个数）。
解析规则：以 `## <节名>` 开头，到下一个 `## ` 为止；节内以 `>` 开头的行是说明，不进入提示词。
