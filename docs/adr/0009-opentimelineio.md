# ADR-0009：以 OpenTimelineIO 作为时间线格式

- **状态**：Proposed
- **日期**：2026-09-30
- **决策人**：@shiyunche44-collab
- **关联**：架构文档 §5.7

## 背景

剪辑合成需要一个中间时间线表示：平台内渲染要用，导出给专业剪辑软件做人工精修也要用。

## 决策

- 时间线统一用 OpenTimelineIO（OTIO）表示，由 DramaIR + 选定的 Take 自动生成。
- 平台渲染器读取 OTIO 生成 FFmpeg 渲染图；导出时转换为 FCPXML 等格式。
- 平台特有的信息（花字模板、AIGC 标识层等）放在 OTIO 的 metadata 中。

## 备选方案

| 方案 | 不选的原因 |
|---|---|
| 自定义时间线 JSON | 需要自己写与专业剪辑软件之间的转换，且缺少现成工具 |

## 后果

- 正面：行业标准，有现成的转换适配器；便于人工精修回流。
- 负面：OTIO 的某些效果表达能力有限，需要约定 metadata 扩展。
- 约束：渲染器只接受 OTIO 输入，不从其他路径拼装时间线。

## 复审条件

OTIO 无法表达的平台特效需求占比明显上升。
