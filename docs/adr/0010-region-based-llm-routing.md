# ADR-0010：LLM 按部署区域路由以满足合规

- **状态**：Proposed
- **日期**：2026-09-30
- **决策人**：@shiyunche44-collab
- **关联**：架构文档 §5.1.4、§13；不变量 INV-01、INV-08

## 背景

在中国境内面向公众提供生成式 AI 服务，需要使用已完成备案的大模型服务；出海业务则需要满足数据驻留和当地的透明度要求。平台需要同时服务两类区域。

## 决策

- 模型网关按**部署区域**选择模型：国内区域只路由到已备案的模型服务，海外区域可以使用 Claude 等海外模型。
- 区域是网关路由的硬约束，业务代码不感知、也不能覆盖。
- 各区域数据独立存储，不跨境回传。
- 每个区域的可用模型清单维护在网关配置中，并随合规要求变化更新。

## 备选方案

| 方案 | 不选的原因 |
|---|---|
| 全球统一使用同一模型 | 不满足国内合规要求 |
| 由业务代码按区域选择模型 | 违反 ADR-0004，且容易遗漏 |

## 后果

- 正面：合规在架构层面保证，不依赖每个开发者的记忆。
- 负面：不同区域的生成质量可能不同，需要分区域维护评测集和 prompt 模板。
- 约束：网关配置中区域与模型的对应关系变更需要合规负责人评审。

## 复审条件

相关法规或备案要求发生变化。
