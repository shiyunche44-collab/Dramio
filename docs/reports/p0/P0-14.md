# P0-14 P0 复盘：评测总报告

> 日期：2026-10-13 · 范围：P0-02 ~ P0-13 · 本文只汇总既有报告的结论，不重新计算；每个数字标注类型：**实测**（本项目运行得到）、**外推**（由实测推出，写明前提）、**未验证**。
> 状态：**待用户确认**（D-020 ~ D-023）。ADR 状态、Schema、P2 目标数值都由用户决定，本步没有改动任何 ADR 的状态。

## 1. 一页结论

- **P0 的核心问题——“能不能无人工干预把一句话梗概变成成片，并且重复运行近乎零成本”——答案是能**：`python3 -m poc run` 从梗概到 1080×1920 成片全程无人工干预（P0-12，实测）；同样输入热运行全部命中缓存、费用 ¥0；3 集共 63 镜头的规模抽测全部成功（P0-13，实测）。node_key 缓存的设计被验证可用（ADR-0006）。
- **但 P0 的业务退出标准只“部分满足”**：成片里没有一个真实视频镜头（MiniMax 视频额度用尽），没有口型，没有 BGM / SFX（P0-10 未做，缺火山 AK/SK）；“全自动 + 真实视频 + 口型 + 音乐”从未同时成立。这些缺口都落在 P1-12 ~ P1-16 的范围内，建议带缺口进入 P1（需要用户决定，D-020 之外的选择见 §8）。
- **质量风险集中在三处**：双人镜头的角色一致性（13 个不达标实例里 12 个）、分镜时长与配音时长不闭环（63 个镜头里 28 个台词超出，10 个 > 0.3 秒）、音色池太小（10 个角色里 4 个复用）。
- **成本**：占位口径每成片分钟 ¥8.6（实测，Ark 部分为 Agent Plan 等价费用）；加上真实视频外推约 ¥47–48 / 分钟；视频占 90% 以上（外推）。
- **环境约束**：Ark Agent Plan 月度额度已用尽，至 2026-11-01 才重置（实测，P0-13 §6），期间无法生成新的定妆 / 首帧；MiniMax 视频额度仍用尽（429 `2056`）。

## 3. 四个问题的回答（汇总 P0-13 §2）

| 问题 | 回答 | 类型 |
|---|---|---|
| Q1 角色一致性能否稳定达标 | **部分**：首帧单人镜头基本稳定，双人镜头需要多候选打分选优（P1-12）；视频阶段的漂移、跨集一致性**未验证** | 实测（首帧）/ 未验证 |
| Q2 单集成本与耗时 | 占位口径每集 ¥8.6–10.1、33–39 分钟；整集真实视频外推每集约 ¥49–56、约 1.5 小时 | 实测 / 外推 |
| Q3 口型能否可播出 | **P0 没有给出可播出的结论**：P0-09 只有 3 个单人镜头，无逐片段评分；P0-13 无新增数据；双人对白占对白镜头的 17%（6 / 35） | 部分实测 / 未验证 |
| Q4 哪个环节返工最多 | 首帧（自动代理指标：22% 实例低于 τ）；其次是分镜时长与配音时长不闭环（16% 的镜头台词超出 > 0.3 秒） | 实测（代理指标） |
