# P0-12 一键串联

> 命令：`cd spikes/poc && python3 -m poc run --logline "…"`；引擎 `poc/pipeline.py`，节点哈希 `poc/nodekey.py`，缓存 `poc/nodecache.py`，用法见 `spikes/poc/README.md` 的 `run` 一节。

## 1. 结论

- **无人工干预**：梗概“雨夜，被陷害的设计师当众撕开真相，却发现幕后黑手是自己最信任的人。”→ 成片，全程没有手选定妆、首帧、音色，也没有改文件。成片 `cold/final.mp4`：1080×1920、24 fps、h264 + aac、59.67 秒、15.5 MB，`run --verify` 通过（规格、AIGC 元数据与角标、字幕条数 10 = 台词数 10、manifest 费用 = calls.jsonl 合计、无密钥）。
- **缓存命中**：同样输入第二次运行，58 个节点全部命中、0 次供应商调用、费用 ¥0、耗时 0.56 秒（冷运行 1582 秒）。
- **增量重算**：`--reroll keyframe:ep01_sc01_sh03 --reroll tts:l_0003` 只重算这 2 个生成节点加受影响的 4 个合成节点（该镜头与 `ep01_sc02_sh01` 的 segment、audio_mix、final），费用 ¥0.33，耗时 166 秒，其余 52 个节点命中。
- **视频额度用尽时**：`--video auto` 只提交 1 次（被 MiniMax 429 `2056` 拒绝，不计费），其余 18 个镜头立即降级，退出码 0，`degraded[]` 如实列出 19 个镜头及原因；`--video h3` / `--require-real-video` 同样条件退出码 1。
- **node_key 思路成立**，但 INV-05 里“网关拒绝缺少幂等键的请求”要等 P1 的模型网关才能验证；本步只验证了 key 的设计与命中逻辑。

**未验证（需如实说明）**：真实视频没有进入串联——MiniMax 视频额度仍用尽（429 `2056`），所以成片里 19 个镜头全是首帧缓推占位，没有一个真实视频；“成片全是真实视频”和整集真实视频的耗时 / 费用只能按 P0-08 的数据外推（H3 768P ¥0.50 / 秒，约 59 秒 ≈ ¥30）。

## 3. 冷运行（`cold/`）

冷运行被工具的 590 秒超时打断过一次，之后用同一缓存续跑，所以费用分两段（`cold/calls-part1-interrupted.jsonl` + `cold/calls.jsonl`）：

| 阶段 | 节点 | 费用（估算） | 说明 |
|---|---|---|---|
| script + shots | 2 | ¥0.17 | DeepSeek flash，各一次通过；生成 3 个角色、19 个镜头、10 句台词、59 秒 |
| costume | 6（3 角色 × 主图 + neutral） | 约 ¥1.9 | Agent Plan 的 pro 按刊例价等价计，不实付 |
| tts + ASR | 10 | ¥0.05 | 方案 C，ASR 回检 |
| keyframe ref2 | 19 | 约 ¥6.4 | 其中一次 `ConnectionResetError` 记 ¥0.32（`Runner` 对网络错误保守按计费算），重试成功 |
| video | 0 | ¥0 | `--video placeholder` |
| compose | 19 segment + audio_mix + final | ¥0 | 193 秒（冷） |
| **合计** | | **约 ¥8.5** | |

耗时：keyframe 1389 秒（串行，约 73 秒 / 张）占 88%，compose 193 秒；LLM 与 tts 合计不到 2 分钟。**串行执行的首帧是 P1 的主要提速点**（并发 + 批量）。

## 4. 自动化过程中发现的缺口

1. **音色池只有 2 个音色**（D-004）：这个梗概有 2 个女性角色（`char_linwan`、`char_suman`），自动复用同一个女声，听感会混淆；已记入 manifest 的 `warnings`。P1 需要音色库和按角色描述挑选。
2. **首帧 / 定妆无质量把关**：自动取第 1 张，不做人脸相似度打分重试（P0-07 已见 `ref2` 有 1 个错人实例）。P1-12 做“多候选 + 打分选优”，成本约翻倍。
3. **镜头时长**：`ep01_sc02_sh01` 的台词需要 3.79 秒、比 hint 3.5 秒长，合成时已自动延长；`shots` 与 TTS 的时长闭环（先配音再定镜头时长）留给 P1。
4. **`shots` 失败有回退**（用 script 自带镜头并记 `degraded`），本次两个 LLM 阶段都一次通过，回退路径只有离线测试覆盖。
5. **缓存未做并发、无淘汰**：`runs/pipeline-cache` 当前 74 MB；P1 的 CAS 在对象存储上。
6. **口型（D-016 路线 C）与 BGM / SFX（P0-10）未接入**：OTIO 的 A3 / A4 保持空轨。
7. 成片的角色 / 场景由 LLM 自由生成，**没有做内容审核**（P1 的质检环节）。
