# P0-03 剧本生成：结论

> 一句话梗概 → 1 集 DramaIR v0 剧本。评测日期 2026-09-30。代码：`spikes/poc/poc/script.py`；用法见 [spikes/poc/README.md](../../../spikes/poc/README.md#script剧本生成p0-03)。

## 结论

- **可行**：三个候选（都是 DeepSeek）各连续生成 5 份，**15/15 全部通过 DramaIR v0 严格校验**（0 错误、0 警告），每份最多修复 2 轮。
- **推荐默认方案：`deepseek-flash`（默认开启思维链）**。它的 agent 初评质量最高（均分 3.89），首次通过 4/5（另 1 份修复 1 轮后通过），每集约 ¥0.10（估算上界）、约 53 秒。
- `deepseek-v4-pro` 的结构稳定性最好（首次通过 5/5），但剧情和台词更套路化（均分 3.43），费用约 2.3 倍、耗时约 2 倍。**不推荐**作为默认方案。
- `deepseek-flash` 关闭思维链最便宜、最快（约 ¥0.05、22 秒），质量略低于默认模式（均分 3.72）。适合批量草稿或重试兜底。
- **待用户确认**：人工评分和推荐方案，见待决事项 D-003。在此之前 P0-03 保持 🔄。
- **未完成跨供应商对比**：只有 DeepSeek 有密钥且网络可达。Anthropic、Gemini、DashScope、Ark 的对比待补测，见[待补测](#待补测)。

## 方法

| 项 | 设置 |
|---|---|
| 输入 | 标准样例 `packages/drama-ir/examples/v0/ep01.json` 的 `series.logline`（D-002 固定输入，sha256 `cd02daef022c…`）：“被上司抢走方案、雨夜被辞退的设计师，在离职纸箱里发现一枚神秘 U 盘，决定当众反击。” |
| Prompt | `script.v1`（[模板](../../../spikes/poc/poc/prompts/script.v1.md)；渲染后的完整消息见 [P0-03/prompt.script.v1.json](P0-03/prompt.script.v1.json)）。system 消息包含三部分：创作要求（开篇钩子、爽点、集尾卡点）、11 条数据规则（阈值在运行时取自 `dramio_drama_ir.checks`）、完整的 v0 Schema（去掉 `$schema`、`$id`）。约 2.7k 输入 tokens |
| 调用 | OpenAI 兼容 Chat Completions，开启 JSON 模式（`response_format=json_object`），`max_tokens=32000`，temperature 用供应商默认值 |
| 通过口径 | 同一次运行顺序生成 5 份，不挑选、不丢弃。每份最终产物必须满足：`validate` 没有错误**也没有警告**（strict），只有 1 集，`series.logline` 与输入逐字一致。不通过时把上一版输出和问题清单（带 JSON 路径，最多 30 条）回喂给模型，要求重写完整 JSON，每份最多修复 2 轮。任何一份失败都判整批失败 |
| 计费 | 按 usage 和 `poc/pricing.py` 的单价估算（`cost_basis=estimate`）。单价是保守的上界，用账户余额差复核，见[费用](#费用) |

三个批次在同一时刻并行启动；每个批次内部的 5 份按顺序生成。

## 评分

### 评分表

每个维度 1–5 分：5 优秀，4 良好可用，3 及格但需修改，2 明显缺陷，1 不可用。

| 维度 | 看什么 |
|---|---|
| D1 开篇钩子 | 前 3 秒是否有冲突、悬念或强视觉 |
| D2 结构节奏 | 爽点（反转、打脸、揭露）密度；集尾是否留卡点 |
| D3 人物 | 人设是否鲜明，动机是否一致 |
| D4 台词 | 是否口语化、符合人设、长度适合配音 |
| D5 逻辑自洽 | 因果、时空、道具是否前后一致 |
| D6 可拍性 | 画面描述是否具体；景别、运镜、时长是否合理（服务 P0-04 ~ P0-07） |
| D7 梗概贴合 | 是否覆盖梗概要素：抢方案、雨夜辞退、纸箱 U 盘、当众反击 |
| 合规 | 通过 / 不通过（违法、色情、血腥暴力细节，影射真实人物或品牌） |

均分取 D1 ~ D7 的平均值。任何一个维度低于 3 分即判为“不可用”。

## 推荐

1. **默认 LLM 用 `deepseek-flash`，保持思维链默认开启。** 它在质量、稳定性和费用之间最均衡。
2. **结构兜底用“严格校验 + 最多 2 轮修复”。** 18 份（含冒烟）中 15 份首次通过，其余 3 份全部在 2 轮内修复。产品化后，这部分对应 P1-19 的审稿打回机制。
3. **关闭思维链的 flash 作为低成本档。** 用于批量草稿、分支试写，以及主模型失败时的重试。
4. **Prompt 的下一版（v2）先不做。** 当前的失败都能被修复，而且各不相同，没有集中的系统性问题。

## 对 DramaIR v0 的修订建议（留给 P0-14）

- **情绪枚举偏少**：模型自发用了 `suspicious`。建议评估是否加入 `suspicious`、`determined` 这类短剧常用的情绪。
- **场标题与镜头地点可能不一致**：例如 v4-pro 冒烟样本（`20260930-121407-script-c9e2`）第 4 场标为“写字楼门口”，镜头里人物却走进了大厅。v0 的地点只在场上，没有检查手段。P1 的 Location 实体可以解决这个问题。
- **集标题语言**：flash s05 的集标题出现了繁体字，而 `series.language` 是 `zh-CN`。可以考虑增加一条文本语言一致性的警告规则。
- Prompt 迁入 `packages/prompts`、接入评测回归，按路线图在 P1-17 / P1-20 进行。
