# 火山引擎能力盘点（供 P0 选型参考）

> 调研日期：2026-09-30。来源：火山引擎文档中心 `docs.volcengine.com`（289 个文档库，本文只精读与 Dramio 生产链路相关的约 20 个）。
> 价格、模型 ID、限额以文档当日内容为准，调用前以控制台和 API 返回为准。文中 `doc 6448/2658349` 表示文档库 ID / 文档 ID，可拼成 `https://docs.volcengine.com/docs/<库>/<文档>` 查看原文。
> 本文只是资料，不是选型结论；各步骤的默认方案仍由对应 P0 步骤的评测决定。

## 1. 结论

1. **火山引擎能单独覆盖 P0-03 ~ P0-11 的每一个环节**：LLM、TTS / 声音复刻、图像、视频（含原生有声视频）、口型同步（3 种路线）、音乐 / BGM、剪辑合成、AIGC 标识、内容审核、对象存储。可以作为除 DeepSeek 之外的第二家“全能力”供应商，对应 `docs/architecture.md` 中“第三方供应商至少准备两家可互相替代”的要求。
2. **两套入口就够用**：
   - **火山方舟**（`ark.cn-beijing.volces.com`，`ARK_API_KEY`，Bearer）：LLM、Seedream 图像、Seedance 视频、Seed3D、向量。**当前容器已可访问**（无密钥返回 401）。
   - **AI MediaKit**（`mediakit.cn-beijing.volces.com`，MediaKit API Key，Bearer）：口型对齐、剪辑合成、字幕、AIGC 标识等几十个媒体工具，并且可以**代理调用**方舟的图像 / 视频模型和豆包语音的 Seed Audio、ASR（`POST /api/v1/tools/call-maas-proxy`，模型费用仍按方舟 / 豆包语音计费）。**当前被网络策略拦截**。
   - 豆包语音的 TTS 2.0 / 声音复刻走自己的接口（`x-api-key` 头），接口文档页本次读不到（见 §9），域名待核实。
3. **与 P0 直接相关的三个发现**：
   - **Seedance 2.0 / 2.5 能直接生成有声视频**（`generate_audio=true`，提示词里台词用 `{}`、音效 `<>`、音乐 `()`），这就是 P0-09 “原生音画同步”路线的候选，可以和“先配音再改口型”路线对比。
   - **Seedance 不接受直接上传的真人人脸参考图 / 视频**。只信任同账号下 30 天内由 Seedance 2.x 或 Seedream 5.0 lite/pro **文生图**产出的含人脸原始文件（不能二次剪辑、不能跨账号），或平台预置虚拟人像、经活体认证授权的真人素材。这会直接约束 P0-06 定妆 → P0-07 关键帧 → P0-08 图生视频的链路设计（写实风格尤其如此），也意味着产物要保留原始文件（与 INV-06 CAS 原样存储一致）。
   - 火山自家已有同类产品：**火山剧创**（Web 平台，剧本 → 设定 → 分镜 → 视频，Seedance 2.x 驱动）和**小云雀-短剧漫剧 Agent**（API：剧本解析 → 图片 → 分镜视频 → 单集合成）。可作为 P0 效果对标对象，也提示我们的差异化不能只是“串起来”。
4. **按 ep01（60 秒、13 镜、15 句 207 字台词）粗估的单集费用**：配音 ≈ ¥0.06（TTS 2.0）；定妆图 ≈ ¥0.12–0.6 / 张；视频 720p 无声 ≈ ¥12–60（Seedance 2.0 mini ~ 2.0，见 §3.3）；口型对齐 ≈ ¥1（MediaKit，按输出分钟）；BGM 1 分钟 ≈ ¥0.1；剪辑合成 < ¥0.1。**视频占总费用 90% 以上**，P0-08 的 ¥100 步骤上限只够 2.0 标准版在 720p 下跑 1～2 集。

## 3. 火山方舟（MaaS 平台）

来源：模型列表 doc 82379/1330310、模型价格 82379/1544106、Seedance 2.5 教程 82379/2607688、Seedance 2.0 教程 82379/2291680、肖像素材指南 82379/2608626、创建视频生成任务 82379/1520757。

### 3.1 大语言模型

- 在售：`doubao-seed-2-1-pro-260915`、`doubao-seed-2-1-lite-260915`、`doubao-seed-2-1-turbo-260628`、`doubao-seed-2-0-{pro,lite,mini}-260428`、`doubao-seed-character-260628`、`doubao-seed-evolving`（周级迭代）、`doubao-seed-translation-250915`、`deepseek-v4-1-flash-260910`、`deepseek-v4-{pro,flash}-ga`、`glm-5-2-260617`、`glm-5-3-flash-260828`。
- 能力：深度思考（可关闭）、工具调用、结构化输出（json_schema）、前缀 / Session 缓存、批量推理（约半价）。上下文 256k（Seed 2.x）到 1024k（Seed 2.1 pro、evolving、deepseek）。
- 限流：Seed 2.x 为 RPM 30000 / TPM 500 万；deepseek-v4.1-flash 为 RPM 500 / TPM 100 万。
- 对 P0-03 / P0-04 的意义：方舟上的 `deepseek-v4-1-flash` 与当前默认的 DeepSeek 官方 `deepseek-flash` 是同一模型，可作为同模型的第二供应商（高峰时段价格翻倍）。

### 3.3 Seedance 视频

| 模型 | 时长 | 分辨率 | 并发（企业 / 个人） | 5 秒 720p 价格（无输入视频） |
|---|---|---|---|---|

| doubao-seedance-2-0-260128 | 4–15 秒 | 480p–4K | 10 / 3（4K 为 1） | ¥4.97（¥0.99 / 秒） |

## 4. 豆包语音

来源：产品简介 doc 6561/163032、模型列表 6561/2499930、计费说明 6561/1359370、API Key 6561/1816214、音色列表 6561/1257544。

- **TTS 2.0**：大量预置音色（音色列表中有角色演绎类音色，如“调皮公主”）；支持句级时间戳（`enable_subtitle`，可直接用于字幕和口型对齐）、语音指令（`context_texts`，控制情绪 / 语气）、SSML 标签；17 种语言。
- **声音复刻 2.0**：少量参考音频复刻音色，复刻后以 Speaker ID 调用；需占用音色槽位（¥138 / 个起）。
- **音色设计**：输入角色图片或描述，自动生成贴合形象的音色。适合给 DramaIR 中的角色自动配音色（火山剧创的“智能音色”思路类似：按角色设定生成音色提示词，再用 Seed Audio 1.0 合成）。
- **Seed Audio 1.0**：单条 prompt（≤3k 字符，人声文本建议 ≤400 字）生成包含多角色对白、配乐、音效的整段音频，最长 2 分钟；可带 1 张图和最多 3 条参考音频；只支持中英文；带 AIGC 标识。¥1 / 分钟。
- 其他：流式 / 录音文件 ASR 2.0、端到端实时语音、语音播客、同声传译、机器翻译。
- 鉴权：新版控制台的 API Key，请求头 `x-api-key: <key>`（不再需要 appid）。

## 5. AI MediaKit（媒体处理工具集）

来源：视频口型对齐 doc 6448/2658349、视频工具计费 6448/2486473、剪辑工具计费 6448/2486459、多源输入 6448/2536893、MaaS 代理系列 6448/2700929 ~ 2700932、多轨道剪辑 6448/2673939、AIGC 标识 6448/2658348。

- **统一接口**：`POST https://mediakit.cn-beijing.volces.com/api/v1/tools/<工具名>` 提交异步任务，`GET /api/v1/tasks/{task_id}` 轮询或用事件回调；`Authorization: Bearer <MediaKit API Key>`。
- **输入**：公网 URL、`mediakit://`（先调 `tools-sync/request-media-upload-url` 取预签名 PUT 地址，单文件 ≤5 GB，保留 30 天）、`vod://`、`tos://`。产物可自动存到 VOD / TOS；产物下载链接 24 小时有效。
- **视频口型对齐**（`lip-sync`）：人物视频（mp4、单人真人正脸、偏转 ≤45°、俯仰 ≤15°、不支持 HDR）+ 驱动音频；`enable_video_loop` 在音频较长时镜像循环画面。¥1 / 分钟，耗时约为音频时长的 6～8 倍。
- **剪辑工具**：多轨道剪辑、音视频拼接 / 裁剪 / 调速 / 合成、音频混合、音量与淡入淡出、视频加字幕 / 图片 / 滤镜 / 运镜、图片转视频、智能剪辑 Vibe Editing（自然语言描述剪辑意图），以及**添加 AIGC 元数据标识**。
- **视频 AI 工具**：画质增强、极智超清、视频插帧、字幕擦除、场景切分、语音转字幕、OCR 字幕、高光智剪（短剧）、剧情故事线分析、**剧本还原**（短剧视频 → 结构化剧本）、解说视频生成（短剧行业模型）、视频横转竖、人脸打码、视频画质检测 VQScore、流畅度检测。
- **音频工具**：人声背景音分离、语音端点识别、音频内容编辑、音频转码。
- **MaaS 代理**：`POST /api/v1/tools/call-maas-proxy`，`api` 取 `ark.image_generation`、`ark.video_generation`、`doubao.audio_generation`（Seed Audio）或语音识别，需先在 MediaKit 控制台授权访问方舟 / 豆包语音。模型费用由方舟 / 豆包语音计费，MediaKit 不额外收费。意义：**只放行一个域名、配一个 Key，就能打通图像、视频、音频生成加口型和剪辑**。代价是多了一层代理，返回的是原始结果的包装（`result.maas_result`）。
