# P2 量化目标提案（P0-14）

> governance §7.3 要求 P0 结束时为 P2 设定量化目标（成本、QC 通过率）。本文是**提案，需用户确认**（D-022）。基线全部来自 P0-12 / P0-13，成本为估算或外推，口径见每行说明。

## 口径提醒（影响预算判断）

- P0 的 Ark（定妆、首帧）费用是 **Agent Plan 的按量刊例价等价估算，不是实付**。P0-13 3 集合计 ¥27.94 里 ¥27.14 属于此类，真实付费只有 DeepSeek 与豆包语音约 ¥0.8。按量付费或自建时的真实成本要按刊例价计，所以目标按**等价费用**设定。
- 视频成本只有外推（H3 768P ¥0.50 / 秒，`min(15, max(4, int(hint_s)))` 秒 / 镜头）；口型、BGM / SFX、失败重试、多候选首帧的成本**没有数据**。

## 需要用户确认

1. 成本目标 ¥45 / 成片分钟是否合理，是否按**等价刊例价**口径；
2. “QC 自动通过率”和“人工返工率”只能写“P1-28 后设定”，是否接受（P0 没有数据支撑，写数字会是编造）；
3. 一致性通过率 95% 的度量口径（τ=0.45、bank、可度量实例）是否沿用。
