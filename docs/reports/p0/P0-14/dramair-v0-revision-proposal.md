# DramaIR v0 修订提案（P0-14）

> 状态：**提案，未改 Schema**。`packages/drama-ir/schema/v0/` 与冻结样例 `ep01.json`（D-002）本步不动；是否采纳由用户在 D-023 决定。实际变更并入 P1-03（Schema v1 + 生成类型），主版本升级需要 ADR-0012（草案已写，Proposed）。

## 为什么不在 P0-14 直接改 v0

- v0 所有字段必填且 `additionalProperties: false`：加必填字段会让冻结的 ep01 和 P0 全部 LLM 结构化输出失效；
- 校验器是手写的 JSON Schema 子集（TD-001），没有兼容性检查，改动没有安全网；P1-03 才引入生成类型与向后兼容 CI；
- 下表里需要新实体或改语义的项，按 ADR-0002 都要 ADR。

## 提案清单

分类：**v0.x**＝向后兼容的小改（可选字段、枚举扩展），可在 P1-03 之前做；**v1**＝并入 P1-03，需 ADR-0012；**校验策略**＝不改 Schema，只改校验器 / Prompt；**不做**。
