# P0-07 关键帧与一致性度量

> 日期：2026-09-30 · 步骤卡与进度见 [progress.md](../../progress.md) · 上游：[P0-06 角色定妆](P0-06.md)、[P0-04 分镜](P0-04.md)
> 结论状态：**推荐方案 `ref2`；默认方案与目视评分需用户确认（D-011）。**

## 1. 结论

- **推荐一致性方案：`ref2`**（每个出镜角色带 2 张参考图：P0-06 选定的 pro `main-02` + 正面 neutral 特写；文字只描述场景、姿态、构图、服装）。12 个带角色镜头、2 轮共 26 个可度量人脸实例中，92% 的相似度 ≥ τ=0.45，P10 为 0.48（三个方案里最高）。
- `ref1`（每角色 1 张 `main-02`）中位数最高（0.63–0.67），但下尾更差：最差的实例只有 0.20，2 轮里有 2 个实例 < 0.30。`text`（纯文字）中位数 0.44–0.49，只有 54–62% ≥ τ。
- **按预设判据，严格说没有方案完全达标**：判据要求“无错人实例（< 0.30）”。`ref2` 有 1 个（2 轮 26 个实例里的 r1 `sc01_sh05` 陆沉 0.296）。目视核对这张图：两个角色的脸都对（眼镜、发型、脸型与参考图一致），只是两人侧脸对视、脸 112 px，ArcFace 对侧脸的相似度天然偏低，属于度量的误判，不是换脸。这一项我按“度量局限”处理，但它是我在看到结果后对规则的解释，已登记给用户确认（D-011）。
- 度量有效：在 P0-06 的 86 张定妆图上，度量排序与当时的目视初评一致（见 §5）。
- 首帧全部 13 个镜头已生成并选定 1 张（`selected`），1152×2048、9:16、无字幕文字、底部留白，P0-08 直接读取（§8）。
- 费用：两轮生成 + 冒烟共 ¥24.52（Agent Plan 等价费用，不实付；口径同 P0-06），远低于步骤上限 ¥100。

## 2. 输入与做法

- 固定输入 `packages/drama-ir/examples/v0/ep01.json`（sha256 `cd02daef022c…`，D-002 冻结），13 镜头：1 个空镜，12 个带角色；其中 `sc02_sh02` 是手部特写（没有脸），`sc02_sh01` 是俯拍远景，两者预标注为“可能不可度量”，`sc01_sh03` / `sc01_sh05` 是双人镜头。
- 模型：Seedream 5.0 pro（Agent Plan，`ARK_BILLING=plan`），1152×2048（9:16，1.5K 档，pro ¥0.30 / 张，第 2 张参考图起每张 +¥0.02），`watermark=false`（D-005），图片用 `b64_json`。Prompt 模板 `keyframe.v1`（字段运行时取自 ep01：`series.visual_style`、`scene.setting`、`shot.framing`、`description`、`lighting`、`characters[].action / emotion`、角色 `appearance / costume`）。只描述镜头起始姿态，不画动作过程；不含字幕文字，底部 1/4 留作字幕安全区。
- 三种方案：

| 方案 | 参考图 | 双人镜头的参考图数 |
|---|---|---|
| `text` | 无，外貌与服装全靠文字 | 0 |
| `ref1` | 每个出镜角色 1 张：pro `main-02` | 2 |
| `ref2` | 每个出镜角色 2 张：pro `main-02` + `derive-ref-pro` 的 `expression-neutral` | 4 |

  带参考图时，提示词写明“图 1 是某某的全身定妆照……参考图只用于确定人物身份，场景、姿态、构图、服装以文字为准”。空镜各方案共用 1 张。
- 每个方案 12 个镜头 + 1 张空镜，共 37 张一轮，跑 2 轮（r1 入库，r2 只留统计），两轮互相独立（无 seed）。
- 人脸度量：`python3 -m poc face`，insightface `buffalo_l`（SCRFD 检测 + ArcFace `w600k_r50`，CPU），脸框短边 ≥ 40 px 且检测分 ≥ 0.5 才度量。相似度是与参考图的余弦相似度，两种口径：`anchor`（只比 `main-02`）和 `bank`（对 `main-02` 与 neutral 特写取最大值）。**本报告的 τ 与分布以 `anchor` 为准**，因为 τ 是用单张 `main-02` 校准的；`bank` 作补充（对 `ref2` 有利，因为 neutral 特写正好是它的输入）。
- 多人镜头：脸与角色做最优指派（穷举，总相似度最大）；脸数多于角色数时（背景里有路人）默认只取面积最大的 N 张（画面主体），`--pick best` 取相似度最高的作对照（会高估）。

## 5. 度量有效性与校准（零成本，P0-06 的 86 张定妆图）

完整数据在 [P0-07/calibration.json](P0-07/calibration.json)。以两个角色的 pro `main-02` 为锚点：

| 图像集 | 陆沉 中位 | 苏晚 中位 |
|---|---|---|
| `derive-ref-pro` | 0.62 | 0.64 |
| `derive-text-pro` | 0.51 | 0.52 |
| `derive-sheet-pro` | 0.52 | 0.33 |
| pro 其它主图 | 0.75 | 0.66 |
| flash / v4 主图（他家模型，不同人） | 0.34–0.36 | 0.38–0.44 |

- 排序与 P0-06 目视初评一致：ref 最像，text 有漂移，sheet 不是同一张脸。
- 异性角色互比：中位 0.06–0.08，最大 0.21。
- “同描述但不同脸”的参照（他家模型 flash / v4 主图 + flash 文生图，同性别、同描述，23 个实例）：中位 0.34，P90 0.43，P95 0.46，最大 0.52。据此定 **τ = 0.45**（≈ 不同人参照的 P95），**< 0.30 记为错人区间**（高于异性最大值 0.21，且低于参照的绝大部分）。
- **局限**：
  1. 只有 2 个角色，且没有 pro 模型生成的“同性别真正不同人”样本；pro 自己对同一描述做独立采样本身就偏向同一张脸（`main-pro` 互比 0.64–0.76），所以 `text` 方案的基线本来就不低，`text` 与 `ref*` 的差距可能被低估。
  2. ArcFace 对侧脸、脸小、重光影敏感：首帧里脸 88–150 px 的实例相似度系统性低于全身定妆图；双人侧脸对视镜头（`sc01_sh05`）尤其明显。这类镜头的低分不等于换脸，需要目视复核。
  3. 只度量人脸，没有度量服装、发型、场景；服装一致性靠目视。
  4. 样本小（每方案 r1 13 个实例），分布只能说明趋势。

## 6. 目视抽查（主观，需用户确认）

抽查 r1 的 8 个镜头 × 3 方案共 24 张（`sc01_sh02 / sh03 / sh04 / sh05`、`sc02_sh02 / sh03`、`sc03_sh01 / sh02`）+ 2 张冒烟图，其中 23 张有脸，对照参考图，从“与参考图是同一个人”打 1–5 分（5 = 一眼认出是同一个人）。分数是看图后的粗略估计，只表达相对差别：

| 方案 | 平均分 | 备注 |
|---|---|---|
| `text` | 约 3.8 | 发型、眼镜、服装都对，脸型与参考图略有差别；近景仍像同一个人，说明 pro 对同一描述的默认脸很集中（与 §5 局限 1 一致） |
| `ref1` | 约 4.3 | 单人镜头很稳；双人镜头里苏晚的脸略有不同（与度量一致：`sc01_sh05` 苏晚 0.20） |
| `ref2` | 约 4.4 | 五官、脸型、发型稳定；双人镜头里两个角色都能认出来 |

- 没有发现换脸；抽查的图里服装（米白针织开衫、浅蓝衬衫、黑色直筒裤 / 深灰三件套、银色腕表、金丝眼镜）符合设定，没有发现描述外的配饰。抽查没有覆盖全部 37 张，其余未看。
- **参考图没有被照抄**：背景与姿态均按文字生成，没有出现参考图的灰色棚拍背景；构图没有被参考图带偏。
- 问题：`sc03_*` 会议室镜头里背景出现多张清晰路人脸，这是场景要求“坐满人”的正常结果，但会影响多脸时挑哪张脸去度量（见 §2）。分镜动作是否按文字表现（如递伞）不在本步度量范围，没有逐张核对。
- 评分是 agent 的主观判断，仅作为自动度量的交叉验证。
