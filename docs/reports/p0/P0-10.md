### 3.1 生成纯音乐（doc 84992/2100970，2026-07-24 更新）

| 项 | 文档记载 |
|---|---|
| 接口 | `POST https://open.volcengineapi.com/?Action=GenBGMForTime&Version=2024-08-12`（后付费）；预付费资源包用 `Action=GenBGM`，两者互相独立、不抵扣 |
| 签名 | 火山 OpenAPI V4（HMAC-SHA256）；Region 固定 `cn-beijing`，Service 固定 `imagination`（公共字段 doc 84992/1967910；响应的 `ResponseMetadata` 也印证） |

### 3.2 查询任务与回调（doc 84992/2100960、2100987）

- `POST …?Action=QuerySong&Version=2024-08-12`，请求体 `{"TaskID":"…"}`，同样需要签名。
- 响应 `Result`：`Status`（0 等待 / 1 处理中 / 2 成功 / 3 失败）、`Progress`、`FailureReason`（`Code` / `Msg`，成功为 null）、`SongDetail`：`AudioUrl`（域名规则 `v{1-50}-default.douyinvod.com`）、`Duration`（秒，浮点，**后付费按此计费**）、`Prompt`、`TosPath`、`StyleInfo`（v5.0）等。
- 默认提供 wav，**但视频云链路有默认转码逻辑，可能出现 mp4 等格式**；URL 有效期 1 年，文档要求只作转存使用，不要直接用在应用里。
- 也可传 `CallbackURL`，完成后服务 POST 回调（失败重试 2 次，间隔 5 / 10 分钟）；P0 容器没有公网入口，只用轮询。
- 用量查询 `GET …?Action=QueryUsage&Version=2024-08-12`（doc 84992/2100962）：返回授权状态、`MusicQuota` / `MusicUsed`。**只读查询，文档没有写计费，推断免费**——可作 AK/SK 与开通状态的免费校验（比 `doctor` 现有的“只检查变量”更强），需在线时确认。

### 3.3 计费（doc 84992/1404661，2026-07-24 更新）

- 后付费：**¥0.002 / 秒**，按最终成功生成的时长计；示例 200 秒 = ¥0.4。QPS ≤ 2，公共资源池，高峰可能排队。
- 预付费资源包：纯音乐 200 首试用版（**企业用户首次购买 ¥0，限购一次**，个人用户需付费）、1 万首 ¥15000 / 年等。
- **文档内部不一致**：计费页写“纯音乐支持生成 60 秒以内的 BGM”，接口页写 v5.0 有效范围 [30, 120]——以接口实测为准。
- **只支持企业认证用户购买**（API 快速接入指南 doc 84992/1404668）；建议用子账号 AK/SK 并给子账号授权。

### 3.4 错误码（doc 84992/1404675）

`0` 成功；`100001` 服务内部错误；`100010` 参数错误；`100011` 海外 IP 限制；`200020` 无效签名（注意区分主 / 子账号）；`200021` 授权过期；`200022` 资源包耗尽；`200023` 超 QPS；`200024` 账号音乐功能被禁用；`200026` TOS 桶名称无效；`200027` 资源包过期；`200028` 没有可用资源包；`300030` 算法错误；`300052` 任务未找到；`300061`~`300064` 歌词抄袭 / 不安全；`300065` / `300066` 歌词语言；`300067` 语义识别错误需重试；`400040` 队列已满。（`50000001` 版权校验见 §3.1，表里没有。）

### 3.5 V4 签名（doc 6369/67270，“签名过程 Demo”，2025-09 更新）

- `CanonicalRequest = Method \n CanonicalURI \n CanonicalQueryString \n CanonicalHeaders \n SignedHeaders \n HexEncode(SHA256(body))`；`CanonicalHeaders` 是小写头名排序后的 `name:value\n`（末尾再空一行）。
- `StringToSign = "HMAC-SHA256" \n X-Date \n <ShortDate>/<Region>/<Service>/request \n HexEncode(SHA256(CanonicalRequest))`。
- 派生密钥：`HMAC(HMAC(HMAC(HMAC(SK, ShortDate), Region), Service), "request")`——**起点就是 SK 本身，不加 `AWS4` 前缀**；`Signature = HexEncode(HMAC(signingKey, StringToSign))`。
- `Authorization: HMAC-SHA256 Credential=<AK>/<ShortDate>/<Region>/<Service>/request, SignedHeaders=<h1;h2>, Signature=<sig>`。
- 文档给了一组**完整的示例向量**（公开的文档示例 AK/SK、`iam` 服务的 GET 请求、每一步的中间值与最终签名 `e31c4558…de93`），直接作为单测黄金向量（`tests/test_volc_sign.py`）。

## 4. 对设计的影响（离线阶段已落到代码里的）

1. **单次生成最短 30 秒**：ep01 每场只有约 20 秒，按场景各生成一段会被拒或浪费。规划里 `gen_s = max(30, 段长 + 淡化余量)`，多出的部分在合成时裁掉；费用仍然极低（每段 ¥0.06）。
2. **异步任务**：提交 → `QuerySong` 轮询，客户端按此建模；`Duration` 以返回的 `SongDetail.Duration` 为准（计费依据）。
3. **产物格式不确定**（wav / mp4）：落盘前用 ffprobe 探测，不信文件后缀。
4. **版权校验 `50000001`**：prompt 模板写足描述（曲风、情绪、乐器、场景、速度），避免“简单 30 秒短音乐”。
5. **AK/SK 校验**：`QueryUsage` 作为免费校验候选，在线阶段确认。
